# Просмотр файлов в админке

- Status: draft

## Intent

Владелец открывает файл воркспейса прямо из админки и читает его содержимое, не
покидая страницу «Проекты» и не заходя на сервер. Дерево даёт состав каталогов и
файлов; эта инициатива — чтение отдельного файла, редактирование остаётся за
владельцем вне админки.

## In scope

- Открытие файла из дерева воркспейса: клик по файлу показывает его содержимое.
- Чтение текстовых файлов (текст/код) как есть, read-only; длинный файл — с
  прокруткой.
- Ленивое чтение по запросу: сервер отдаёт содержимое одного файла по пути.
- Контеймент воркспейса: чтение только внутри выбранного воркспейса (дом или
  проект), без выхода за его корень.
- Поведение для нечитаемых, слишком больших и бинарных файлов, а также
  симлинков — понятное сообщение «нельзя показать».
- Состояния: «Загрузка…», ошибка с повтором, пустой файл.

## Out of scope

- Редактирование, сохранение и создание файлов из админки.
- Рендер по типу (markdown-превью, изображения, подсветка синтаксиса) —
  возможное расширение, не первый шаг.
- Загрузка и скачивание файлов, drag-and-drop.
- Показ бинарных файлов как содержимого.
- Права и роли: сервер single-user, доступ владельца не разграничивается.

## Absorbs into

- API_CONTRACTS.md — ручка чтения содержимого файла воркспейса.
- ADMIN_UI.md — поведение центральной зоны дерева при открытии файла.
- ARCHITECTURE.md — серверное чтение файла и граница воркспейса.
- GLOSSARY.md — термины просмотра файла, если появятся.

## Open questions

- Где показывать содержимое: центральная зона (рядом с деревом), модальное окно
  или отдельный экран.
- Лимит размера и признак усечения: с какого размера обрезать и как показывать
  неполный файл.
- Кодировки и бинарные файлы: определять по расширению или по содержимому и что
  показывать вместо содержимого.
- Симлинки: повторять ли контеймент `workspaces.tree` (симлинки не
  разыменовываются) или разрешать чтение цели.
- Переиспользование семантики Telegram-чтения (текст + truncated) или отдельная
  форма ответа для админки.
