# Просмотр файлов в админке

- Status: absorbed

## Intent

Владелец открывает файл воркспейса прямо из админки и читает его содержимое, не
покидая страницу «Проекты» и не заходя на сервер. Дерево даёт состав каталогов и
файлов; эта инициатива — чтение отдельного файла, редактирование остаётся за
владельцем вне админки. Открытые вопросы закрыты утверждённым дизайном
(`docs/superpowers/specs/2026-09-18-file-view-design.md`).

## In scope

- Открытие файла из дерева воркспейса в динамическом табе правой зоны поверх
  незакрываемого таба «Сессии»: клик по листу показывает содержимое, повторный
  клик фокусирует уже открытый таб, «×» закрывает.
- Чтение текстовых файлов (текст/код) как есть, read-only; моноширинный текст с
  независимой прокруткой.
- Ленивое чтение по запросу: сервер отдаёт содержимое одного файла по пути.
- Контеймент воркспейса: чтение только внутри выбранного воркспейса (дом или
  проект), без выхода за его корень — тем же контейментом (лексический и по
  realpath), что у `workspaces.tree`.
- Лимит текста — `DEFAULT_MAX_FILE_BYTES` = 256 КиБ с флагом `truncated`; при
  обрезании UI показывает пометку, а не молча неполный текст.
- Бинарность — по содержимому (NUL в первых 8 КиБ), а не по расширению.
- Симлинки не разыменовываются: финальный симлинк даёт `kind: "link"` и
  сообщение «Символические ссылки не открываются».
- Три формы результата — данные, а не ошибки: отдельная форма ответа
  `WorkspaceFileResult` (`text`/`binary`/`link`) возвращается с HTTP 200.
- Состояния: «Загрузка…», ошибка с повтором, пустой файл, бинарный, симлинк.

## Out of scope

- Редактирование, сохранение и создание файлов из админки.
- Рендер по типу (markdown-превью, изображения, подсветка синтаксиса) —
  возможное расширение, не первый шаг.
- Загрузка и скачивание файлов, drag-and-drop.
- Показ бинарных файлов как содержимого.
- Пагинация и живое обновление открытого файла.
- Права и роли: сервер single-user, доступ владельца не разграничивается.

## Open questions

Пусто: вопросы закрыты утверждённым дизайном — содержимое открывается в
динамическом табе правой зоны; лимит 256 КиБ с признаком усечения; бинарность по
содержимому; симлинки не разыменовываются; отдельная форма ответа
`WorkspaceFileResult`.
